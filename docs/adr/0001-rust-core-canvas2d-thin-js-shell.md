# Rust core owns document, interaction and Canvas2D rendering; thin JavaScript shell

rs-canvas compiles a Rust core to WebAssembly that owns the document model, all interaction logic and all canvas rendering, using Canvas2D via `web-sys` behind a renderer trait; the vanilla-JavaScript shell only builds browser chrome (toolbar, panels, dialogs) and the DOM text-editing overlay. The alternatives were a JavaScript renderer around a Rust model (more web-standard, much less Rust) and a pure-Rust UI via egui/leptos (weaker text-editing ergonomics, larger bundles); Canvas2D was chosen over wgpu/WebGPU because it provides text shaping and measurement for free, works in every browser, and keeps the bundle small — large-board performance comes from viewport culling, dirty-region redraws and a scene/overlay canvas split. A GPU backend (wgpu/Vello) remains a possible swap behind the renderer trait if profiling ever demands it.
