# Triage labels

Use these five labels to move an issue through triage:

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | Waiting on the reporter for more information. |
| `ready-for-agent` | Fully specified and ready for an autonomous agent. |
| `ready-for-human` | Requires human implementation or judgment. |
| `wontfix` | Will not be actioned. |

When a workflow asks for a triage role, apply the matching label above.
